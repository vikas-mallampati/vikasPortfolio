01 / ABOUT

Building data teams can trust.

Batch + streaming
Cloud data platforms
Reliable architecture

I'm a Data Engineer with over 5 years of experience building large-scale data pipelines at Navistar, Capital One, and Myntra.

At Navistar, I work on batch and streaming pipelines using Apache Spark, Kafka, Python, and SQL on AWS, designing dimensional data models, CDC-based incremental pipelines, and event-driven architectures that handle late-arriving data reliably.

Before that, at Capital One, I built data workflows on AWS using S3, EMR, and Glue, developed warehouse models on Snowflake and Redshift, and worked with strict data quality, lineage, and governance standards required for sensitive financial data.

I started my career at Myntra, India's leading fashion e-commerce platform, where I processed over 50 million daily clickstream events using PySpark, Kafka, and Airflow on Azure Databricks, and tuned Spark jobs and Delta Lake storage to improve performance and reduce costs.

Across all three, my work has been the same: building data systems that run reliably at scale and deliver data that teams can trust.
